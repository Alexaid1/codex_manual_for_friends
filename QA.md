# Проверка первой версии

Дата: 7 ноября 2026 года.

## Автоматическая проверка файлов

Команды: `npm run build`, `npm run check`.

- 13 HTML-страниц успешно собраны.
- 333 локальные ссылки и якоря ведут к существующим файлам/элементам.
- Синтаксис JavaScript корректен.
- У всех карточек есть требования, команда, способ удаления, источник и статус проверки.
- У страниц один основной заголовок, русский язык и корректный UTF-8.
- В публичном HTML не найдены проверяемые локальные пути и имя пользователя.
- Проверены основные пары контраста: основной и вторичный текст на фоне, белый текст на зелёной кнопке, зелёные ссылки на белом.

## В браузере

Проверено через встроенный браузер приложения:

- Все 13 страниц на ширинах 360, 768 и 1440 px: нет горизонтального переполнения документа, основной заголовок присутствует.
- Каталог дополнительно проверен на 390 и 1280 px. Главная просмотрена на 390 и 1440 px.
- Windows/macOS переключают соответствующее содержимое; выбор сохраняется после перезагрузки.
- Отметка урока сохраняется; счётчик и продолжение обновляются.
- Сброс прогресса и отмена работают. Исправлено восстановление главной ссылки после сброса.
- Запрос «видео» оставляет одну карточку; неизвестный запрос показывает пустое состояние; сброс возвращает восемь карточек.
- Тег «презентации» оставляет две карточки и сохраняется в URL/после обновления.
- Прямая ссылка на Remotion открывает подробности карточки.
- Кнопка копирования сообщает об успешном копировании.
- Мобильное оглавление открывается и закрывается по Escape.
- Карта интерфейса показывает пояснение выбранной области.
- Демонстрация запускается, ставится на паузу, переключается назад/вперёд и возвращается к первому шагу.
- Отметка пледа в учебном примере сохраняется после обновления; сброс списка работает.
- В просмотренных журналах консоли не было ошибок.

## Без загрузки приложения JavaScript

Временные HTML-копии первого урока и каталога открывались с удалённым тегом загрузки app.js. В DOM не было скриптов: оба маршрута ОС видны, карточки и команды доступны, native details раскрываются, недоступные интерактивные кнопки скрыты. Эти тестовые страницы удалены после проверки.

Это проверка статического содержимого без скрипта приложения, а не изменение глобальной настройки JavaScript браузера. Fallback внутри noscript также проверен в исходниках.

## Границы

- Реальные Windows/macOS-установки приложения на чистые системы не воспроизводились.
- Схемы интерфейса не заменяют точные скриншоты актуальной версии.
- Настоящий Mac, Safari, Firefox и мобильные устройства не использовались для тестирования.
- Reduced motion проверен по CSS и логике; переключение системной настройки браузера в этой сессии не выполнялось. В обычном режиме проверены ручные шаги и пауза.
- Масштаб 200%, печать и screen reader не проверялись вручную.
- Команды каталога сверены с документацией, но каждый MCP и каждый экспорт не запускались. Установленные навыки и прочитанные источники различаются в статусах карточек.
- GitHub Actions workflow подготовлен, но не запускался без репозитория. Публичного сайта пока нет.
- Реальные записи экрана, озвучка и MP4 не создавались.

Скриншоты локальной проверки находятся в `.qa/` и не включаются в Git. Предпросмотр запускается на 127.0.0.1:4173; это адрес на компьютере автора, а не публичная ссылка.
