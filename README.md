# Codex для друзей

Светлый интерактивный учебник на русском языке. Аудитория знакома только с браузерными ChatGPT и Claude. Windows и macOS рассматриваются одинаково подробно.

- [PROJECT_PROMPT.md](PROJECT_PROMPT.md) — подробное задание на сайт, учебные маршруты, каталог, анимацию и проверку качества.
- `TOOLS_AND_SOURCES.md` — личный локальный отчёт о подготовке (исключён из Git); публичные источники находятся на странице sources.html и в карточках каталога.

## Локальный запуск

Нужен Node.js 22+ или актуальная LTS. В папке проекта выполните:

```text
npm run build
npm run check
npm start
```

Откройте http://127.0.0.1:4173. Если PowerShell блокирует npm.ps1, используйте npm.cmd. Дополнительные npm-пакеты для сайта не нужны; npm install не требуется. Сервер работает только на вашем компьютере. Остановка обычного запуска — Ctrl+C.

После редактирования исходников повторите сборку и обновите страницу. `dist/index.html` также можно открыть напрямую, но для проверки используйте локальный HTTP-сервер.

## Что готово

13 HTML-страниц: главная, восемь уроков, каталог, словарь, источники и пример приглашения. Есть переключение ОС, локальный прогресс, копирование с запасным выделением текста, фильтры каталога с URL, управляемая демонстрация и интерактивная карта рабочего места.

Основной текст и карточки существуют в HTML, а не загружаются только JavaScript. Без JavaScript видны оба маршрута ОС. Анимация запускается по нажатию; поддерживается reduced motion. Данные и прогресс хранятся только в браузере. Внешних шрифтов, аналитики, трекеров и API-запросов у сайта нет.

## Где редактировать

| Файл | Содержимое |
| --- | --- |
| content/lessons.mjs | Уроки и готовые запросы |
| data/tools.json | Карточки инструментов |
| scripts/build.mjs | Общая разметка, главная, каталог, справочные страницы |
| src/style.css | Оформление и адаптивность |
| src/app.js | Интерактивность |
| src/invitation.html | Рабочий пример приглашения |
| dist/ | Готовые файлы для размещения |

Редактируйте исходники, затем собирайте dist. Дата проверки фактов задаётся в генераторе; обновляйте её только после реальной перепроверки.

## Публикация на GitHub Pages

Репозиторий и публичный сайт пока не созданы. После выбора аккаунта, имени и видимости репозитория:

1. Загрузите исходники, исключая .qa, локальные конфигурации и личный отчёт TOOLS_AND_SOURCES.md (они перечислены в .gitignore).
2. В Settings → Pages выберите GitHub Actions как источник.
3. В Actions запустите workflow «Publish handbook to GitHub Pages» вручную через Run workflow.
4. Дождитесь успешного deploy и проверьте адрес из Pages.

Workflow запускается только вручную. Публикуется исключительно dist. Абсолютные пути от корня сайта не используются, поэтому сайт пригоден для адреса с подпапкой репозитория.

## Проверки и границы

`npm run check` проверяет внутренние ссылки и якоря, синтаксис JS, обязательные данные каталога, основные контрастные пары и наличие статических маршрутов ОС. Браузерные проверки описаны в QA.md.

Схемы интерфейса не являются скриншотами. Установка приложения на чистые Windows/macOS не воспроизводилась. Работа каждого MCP не заявлена как протестированная: статус указан в карточке. MP4, реальные записи экрана и озвучка ещё не сделаны. Для первой версии используются HTML-демонстрации.
