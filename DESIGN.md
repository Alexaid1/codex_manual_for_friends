# Визуальное решение

Светлый рабочий атлас для взрослых, переходящих от браузерного чата к самостоятельным проектам.

Цвета: фон #F7F8F5, бумага #FFFFFF, текст #202923, вторичный #58645D, акцент #23614C, линии #DCE3DD. Дополнительные мягкие заливки отличают этапы обучения.

Шрифт: системный sans-serif с полной кириллицей (Segoe UI / system-ui). Крупные заголовки с плотным набором, обычный текст 18 px. Моноширинный шрифт только в командах.

Композиция: постоянное оглавление слева; справа вводная часть с живым примером, ниже последовательные главы. Урок — широкие поля, короткие абзацы, пояснения и проверка результата. Мобильный вид — одно оглавление в раскрывающейся панели, один столбец.

```
┌──────────────┬───────────────────────────────────────┐
│ Название     │ Путь обучения          Windows / macOS│
│ Оглавление   ├───────────────────┬───────────────────┤
│ 01 Установка │ Заголовок         │ Запрос → результат│
│ 02 Интерфейс │ Короткое введение │ Управляемая схема │
│ …            ├───────────────────┴───────────────────┤
│ Каталог      │ Последовательность глав и упражнений │
│ Прогресс     │ Практические результаты              │
└──────────────┴───────────────────────────────────────┘
```

Проверка идеи: последовательная нумерация нужна учебному маршруту; демонстрация показывает реальную цель. Отказ от маркетинговых отзывов, декоративной статистики, эффектов при каждой прокрутке. Схемы явно обозначены. Вся анимация запускается человеком.
